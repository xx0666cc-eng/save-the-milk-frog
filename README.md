# 拯救奶村 · Save the Milk Frog

一款 2D 横版动作闯关游戏。扮演奶蛙，闯过六道关卡，击败各路首领，拯救被敌人占领的奶村。

## 试玩方法

- 直接双击 `index.html`，用 Chrome / Edge 打开即可游玩（支持离线游玩）。
- 也可以用本地服务器运行，例如 `python -m http.server 8000`，再访问 `http://localhost:8000`。
- 手机浏览器打开也可以玩，页面提供虚拟按键。

## 操作

| 按键 | 动作 |
| --- | --- |
| A / D | 左右移动 |
| W / S | 上 / 下移动 |
| 空格 | 跳跃 |
| J | 普攻 |
| K | 挑空重击 |
| U | 气流技（消耗 20 笑声值，冷却 3 秒） |
| I | 大招（消耗 100 笑声值） |
| Shift | 冲刺 |
| 按住 F | 防守 |
| Esc | 暂停 |

战斗中击败敌人会获得笑声值，攒满可释放大招；通关可获得奖励，用于强化角色与解锁换装。

## 角色

六种可选形象：原版奶蛙、星月奶蛙、金纹奶士、月华奶尊、林间游蛙、特奶普。部分形象拥有专属技能特效（例如金纹奶士的千樱断空、樱影突斩，月华奶尊的广寒天倾）。

## 文件结构

```text
index.html            游戏入口（用浏览器直接打开）
角色预览.html          角色换装动作预览页
*.js / *.css          游戏脚本与样式
                        —— 均由 index.html 以相对路径加载，请勿移动或重命名
assets/               游戏美术与字体资源（角色、怪物、关卡、特效、换装、立绘等）
vendor/               第三方库（如 Three.js）
场景预览/              场景预览图
docs/                 设计与制作说明文档、预览图
.nojekyll             供 GitHub Pages 使用（禁用 Jekyll 处理）
```

> 注意：根目录的 `.js` / `.css` 文件与 `index.html`、`角色预览.html` 之间是相对路径引用，移动它们会破坏游戏加载，因此请保持在根目录。如需重构目录结构，请同步修改 `index.html` 等文件中的引用路径。
