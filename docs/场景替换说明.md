# 角色专属场景与加长场地

> 本文保留角色专属场景的历史素材说明，包含已退出可选名单的角色。当前主线第一、二关的独立背景、镜头和地面配置统一见 [关卡开发指南](../../LEVEL_DEVELOPMENT_GUIDE.md)。不要用下列历史角色场景替换主线地图。

五张原图作为各自场景的中央区域，两侧接入按原图风格补绘的延伸背景。选定角色并确认后自动切换场景，暂停换装和重新打开游戏也适用。

横向可移动长度为 48 个游戏单位，比上一版增加 50%。按 A / D 或左右方向键走动，镜头会横向滚动并露出两侧区域。同一窗口内的战斗镜头使用固定缩放，画面边缘的箭头提示对手所在方向。远端箭矢、剑气、回旋扇使用同一场地边界。

每张图片单独对齐地面高度，让人物落在其球场、木地板或平台上。图片场景显示时收起旧三维场地，人物、影子和技能叠加于原图之上。未提供专属图片的原版、星际旅者和游侠继续使用已加长的风起之庭。

自由训练仍为所有技能 0 消耗、0 冷却；月华 I 仍以自身施法位置为中心，挑战模式 CD 15 秒。
